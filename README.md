# Vozacta Releases

Canal oficial de descargas verificables de **Vozacta para Windows**.

Vozacta graba reuniones consentidas y transcribe localmente. La beta pública es gratuita, no requiere cuenta y no envía audio ni transcripciones a Vozacta.

## Descargar

- Página pública actual: https://vozacta-web.vercel.app/descargar
- Descarga directa estable: https://github.com/CarlosDLZ/Vozacta-Releases/releases/latest/download/Vozacta-Windows-x64.zip

Cada release incluye SHA-256 y metadata versionada. La beta actual todavía no tiene firma digital; Windows puede mostrar una advertencia. No continúes si el hash no coincide con el publicado.

## Privacidad y soporte

- Privacidad: https://vozacta-web.vercel.app/privacidad
- Términos de beta: https://vozacta-web.vercel.app/terminos
