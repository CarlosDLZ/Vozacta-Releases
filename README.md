# Vozacta Releases

Canal oficial de descargas verificables de **Vozacta para Windows**.

Vozacta graba reuniones consentidas y transcribe localmente. La beta pública es gratuita, no requiere cuenta y no envía audio ni transcripciones a Vozacta.

## Descargar

La versión aprobada más reciente estará disponible en:

- https://github.com/CarlosDLZ/Vozacta-Releases/releases/latest/download/Vozacta-Windows-x64.zip
- Página del producto: https://vozacta.com/descargar

Cada release incluye SHA-256 y metadatos versionados. La beta actual todavía no tiene firma digital; Windows puede mostrar una advertencia. No continúes si el hash no coincide con el publicado.
